## 專案簡介

本專案建置了一個整合 LINE 訊息與 PDF 聖經文獻分析的 **馬太福音 AI 智能助手**。

系統以《聖經·馬太福音》作為核心知識庫，透過 n8n 接收來自 LINE 使用者的提問，檢索經文內容與釋經資料，並由 AI 產生具備深度與溫度的解答，協助使用者研讀經文與了解章節涵義。
