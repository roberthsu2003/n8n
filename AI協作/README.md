## 💡 協作方式一：瀏覽器側邊欄 AI 顧問（免設定・即問即答）

此模式不需要任何後台伺服器設定，只要在瀏覽器打開 n8n 編輯器，就能隨時呼叫 AI 協助！

### 1. Chrome 內建「問問 Gemini」（畫面即時分析）
* **操作方式**：在 Chrome 右上角點擊 Gemini 側邊欄圖示。
* **強項**：自動讀取當前 n8n 畫布畫面，直接詢問：
  > 🗣️ *「請幫我看看畫面中的 IF 節點為什麼沒有分流？」*  
  > 🗣️ *「這個 Code 節點執行失敗，報錯訊息是什麼意思？該如何修改？」*

### 2. Claude in Chrome 擴充套件
* **操作方式**：安裝 Claude 瀏覽器擴充套件，直接在瀏覽器側邊欄與 Claude 對話。
* **強項**：擅長根據當前網頁結構，幫忙產生複製貼上即可使用的 JSON 工作流程或複雜正則表達式。

### 3. ChatGPT in Chrome 擴充套件
* **操作方式**：安裝 ChatGPT 瀏覽器外掛，在 n8n 編輯器旁邊即時諮詢。
* **強項**：快速產生 JavaScript 資料清洗邏輯，協助轉換日期格式、拆解陣列資料。

## ⚡ 協作方式二：對話式 AI 直接控制 n8n（零代碼・OAuth 串接）

想要直接對 AI 說一句話就自動建好整條 n8n 流程嗎？透過官方提供的 **Claude Connector**，只要點擊授權即可完成連線！

```text
你對 Claude 說：「幫我建一個定時抓取天氣並發送到 LINE 的 n8n 工作流程」
      │
      ▼
Claude 透過 Connector 自動在您的 n8n 畫布上建立並連線好所有節點！
```

### Claude.ai 官方 Connector 設定（3 步驟完成）

1. **開啟 n8n MCP 服務**：
   * 進入 n8n ➔ 左下角 **Settings** ➔ 選擇 **Instance-level MCP**。
   * 將 **MCP status** 切換為 **`● Enabled`**（綠色）。
2. **在 Claude.ai 新增連線**：
   * 開啟 Claude.ai ➔ 點選左側 **Customize** 底下的 **Connectors**。
   * 在清單中找到 **n8n**（Type: `Web`）➔ 點選 **`Connect`**。
   * 輸入您的 n8n 公開網址（例如 ngrok 網址），點擊確認。
3. **完成授權**：
   * 瀏覽器彈出授權視窗，點擊「允許授權」，Claude 狀態顯示 **`✓` (已連線)** 即完成！

> 📘 **詳細圖文教學**：請參閱 **[Claude Connector 完整設定手冊](./README1.md)**

## 🛠️ 協作方式三：專業開發者工具（進階工程整合）

如果您習慣在終端機（CLI）或程式碼編輯器中工作，可以使用 **OpenCode**、**Cursor** 等專業工具：

* **全域設定 (Global)**：設定在 `~/.config/opencode/opencode.json`，所有專案皆可共用。
* **專案設定 (Project)**：設定在專案目錄下的 `opencode.json`，供個別專案專屬連線。

> 📘 **進階完整設定**：
> - 完整功能與按鈕剖析：**[n8n Instance-level MCP 連線設定與介面指南 (v2.34.6)](./n8n_mcp_setup_guide.md)**
